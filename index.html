01
Deep Learning CNN Medical AI Computer Vision
10.4 months MAE

RSNA Bone Age Prediction

The RSNA Pediatric Bone Age Challenge involves predicting a child's skeletal maturity from hand X-ray images — a task traditionally done by radiologists who compare X-rays against atlas references. This project builds an end-to-end deep learning pipeline to automate that process with clinical-grade accuracy, achieving a Mean Absolute Error of just 10.4 months.

CNN Architecture

Built a custom Convolutional Neural Network with residual skip connections. Convolutional layers extract spatial features — bone density, epiphyseal plate width, and ossification patterns — progressively from low-level edges to high-level skeletal landmarks across the hand radiograph.

Data Augmentation

Applied random horizontal flipping, rotation (±15°), zoom (up to 20%), brightness/contrast jitter, and Gaussian noise injection to artificially expand the training distribution. This made the model robust to real-world variations in X-ray positioning, exposure, and equipment calibration.

Result — 10.4-Month MAE

Achieved a Mean Absolute Error of 10.4 months on the RSNA test set, which is within the range of inter-radiologist agreement (~10–12 months) and demonstrates that the model can reliably support clinical bone-age assessment without expert supervision.

02
XAI Grad-CAM Score-CAM Interpretability

Explainable AI (XAI) in Image Processing

A natural extension of the RSNA bone age project addressing a critical problem in medical AI: black-box decision-making. Clinicians cannot trust a model they cannot understand. This project applies four state-of-the-art XAI techniques to generate visual saliency maps that reveal exactly which regions of the X-ray the CNN is using to predict bone age — turning an opaque neural network into an auditable, interpretable tool.

Grad-CAM (Gradient-weighted Class Activation Mapping)

Computes the gradient of the prediction score with respect to the final convolutional feature maps. Regions with large positive gradients are highlighted as heat maps overlaid on the X-ray, showing which bone structures most influenced the predicted age. Efficient and widely adopted in medical imaging research.

Grad-CAM++ (Higher-Order Gradients)

An enhancement over Grad-CAM that uses second-order gradient weighting to better capture multiple discriminative regions in a single image — critical when several growth plates simultaneously contribute to the age estimate. Produces sharper, more spatially precise activation maps.

Score-CAM (Gradient-Free Explanation)

Removes the dependency on gradients entirely. Instead, it forward-passes masked versions of the image through the network and weights activation maps by how much each activation channel increases the prediction confidence. Results in more stable and faithful visual explanations, especially in noisy X-ray environments.

Integrated Gradients (Pixel Attribution)

Computes attributions by integrating gradients along a straight path from a baseline (black image) to the actual input. Unlike CAM-based methods, this produces pixel-level importance scores that satisfy the completeness axiom — ensuring attributions sum to the model's output difference, giving a rigorous mathematical guarantee of faithfulness.

03
Python OOP Turtle Game Dev

Ping Pong & Snake Games

Classic arcade games brought to life using pure Python with zero external game engines — a showcase of object-oriented design and the Python standard library.

Pure Python with the Turtle Package

Both games are built exclusively using Python's standard library turtle module — no Pygame, no external frameworks. The turtle module provides a canvas, event loop, and drawing primitives, requiring careful management of timing and frame updates to create smooth game-play without a dedicated game engine.

Object-Oriented Programming Design

Every game entity is a self-contained class. In Ping Pong: Paddle, Ball, and Scoreboard classes. In Snake: Snake, Food, and Scoreboard classes. Each class encapsulates its own state and behavior, allowing clean separation of concerns and easy extension of game logic.

Ping Pong — Collision & Physics

Implements two-player keyboard controls using turtle's onkey event binding. Real-time ball-to-paddle collision detection uses bounding-box intersection checks. The ball velocity vector reflects off paddles and walls, and a scoreboard updates dynamically when a player misses. The main loop uses screen.update() and time.sleep() for frame control.

Snake Game — Growth & Difficulty

The snake body is managed as a list of turtle segments; on eating food, a new segment is appended and each segment follows the position of the one ahead. Boundary and self-collision are detected via coordinate distance checks. Progressive difficulty is achieved by incrementally reducing the sleep delay between frames as the score increases, making the snake faster with time.
